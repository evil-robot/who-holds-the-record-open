# Deviations from the pre-registered state-layer plan

The plan (PLAN.md, sha256 5e9f0d28b3b860c7a8df4a378221ae4922b0ba2d897540cba12118743a961181, commit d295fff) is frozen. Any change is logged here, dated, with the reason, BEFORE the research it affects. No change is made after results are seen.

## D-1. Federal baseline for D2 (copy rights) includes 45 CFR Part 171. Ruled 3 Oct 2026, before any research.

- **Ruling (JAS, 3 Oct 2026):** the federal baseline for D2 is HIPAA (45 CFR 164.524) AND the information blocking rule (45 CFR Part 171, including the fees exception at 171.302 and 171.302(b)(2)). A state earns D2 credit only for a right that goes beyond that combined federal floor.
- **Why:** the federal law audit (analysis/us/FEDERAL_AUDIT.md, finding 2) found that 171.302(b)(2) arguably already places any fee for a patient's own electronic access outside the fees exception. A state "free electronic copy" law may therefore add nothing above federal law, and crediting it would double-count a federal right.
- **Effect on the plan:** D2's "free copy required by law" level counts only where the state right reaches beyond 171 (for example a free paper copy, a free copy for a personal representative, or a deadline shorter than 30 days). Recorded per state as "beyond the federal floor: yes / no / not checked".
- **Caveat carried into the output:** whether 171.302(b)(2) makes electronic access effectively free is one of the questions put to a US health-law practitioner (Alison Pepper, 4A's). If her read differs, a new deviation (D-2) is logged and D2 is re-derived from the stored evidence, not re-researched.
- **Logged before any jurisdiction was researched:** data/us-states/ is empty at the time of this entry.

## D-5. Harness bug fix: the text filters the prompt asks for were not on the allow list. Logged 3 Oct 2026, during the pilot research sessions, before any cross-check.

- **Bug:** the research prompt tells the session to confirm each quote with `curl ... | grep`, but `run_session.sh` allowed only `Bash(curl:*)`, so the permission layer refused every pipe into grep or sed, and any shell variable or loop (DC: 8 refusals, LA: 15, at 09:50 ET). The sessions continued without those commands; they could not confirm quotes in the page text the way the prompt asks.
- **Fix, for the cross-check and the main run:** the allow list adds `Bash(grep:*)`, `Bash(sed:*)`, `Bash(head:*)`, `Bash(tail:*)`, `Bash(tr:*)`, `Bash(wc:*)`, `Bash(cut:*)` and `Bash(pdftotext:*)`. The prompt adds one line: one command per call, no shell variables or loops. `audit_research.py` now accepts a text filter as the first command (reading a page saved in the scratch dir), and adds `../` to its local-path rule so a relative path cannot climb out of the scratch dir. New planted transcripts cover both (one good, two red). Self-tests re-run; hashes re-stamped before the first cross-check.
- **Effect on the pilot:** the two pilot research sessions ran under the old allow list and are reported as such. Their measured cost includes the refused turns, so the projection leans high. Quote verification for them rests on the harness's raw-page check, which does not depend on the session.

## D-6. Audit false alarms found on the first real transcript; three rules narrowed, both directions tested. Logged 3 Oct 2026, after the DC pilot research transcript, before any cross-check.

- **Found:** `audit_research.py` failed the DC pilot research transcript on (a) the D-5 absolute-path rule `(^|\s)/[A-Za-z]`, which matched the sed expression `'s/<[^>]*>/ /g'` and `pdftotext /dev/stdin /dev/stdout`; and (b) "Bash not curl" on `UA="<literal user agent>"; curl -sL -A "$UA" <url> | sed ... | tr ... | head`, which only names a literal string. None opened a local file or an unlisted host. The flagged commands are in the transcripts (`transcripts/pilot_research_DC.jsonl`); PILOT_REPORT.md section 6 lists the shapes.
- **Change:** (a) the generic absolute-path rule now needs a path with two components (`/opt/x`), keeps the explicit roots (/Users, /etc, /private, /var, /tmp, /opt, /usr, /Library, /System, /home, /root, /bin), and exempts /dev/null, /dev/stdin and /dev/stdout. (b) A leading assignment of a quoted literal (`NAME="..."` or `NAME='...'` with no `$`, backtick or `$(`) is stripped before the first-command check; anything else in an assignment still fails. (c) The `-o`/`--output` target check applies only to curl segments of the command, and the pipe check reads `head;` as `head`.
- **Tested both ways:** new good transcripts (the sed expression; the literal UA assignment; pdftotext from stdin) and new red ones (`X=$(cat /etc/passwd); curl`, `` X=`id`; curl ``, `grep x "/opt/secret/file"`), plus every earlier fixture. The DC verdict under the old and the new rules is reported side by side.

## D-7. Raw-page check: two harness fixes found on the DC pilot file. Logged 3 Oct 2026, before any cross-check.

- **Found:** `raw_fetch.py` marked 7 of 14 DC provisions `session` (not fetchable raw) although every page came back HTTP 200 from a server-rendered host. Its usability test required every numbered token of the citation (for example `28-3851(1b),`) to appear in the page text. A `session` mark lets a quote skip the raw check, so this failed in the unsafe direction. Separately, one quote missed only because the page renders a linked word as `subchapter </a>,`, which leaves a space before the comma after tags are stripped.
- **Fix:** a page is usable when it returns 2xx and its normalised text exceeds 200 characters; the citation test is dropped. Normalisation also removes whitespace before `, . ; : )`. Both directions stay safe: a quote absent from a usable page becomes `not_found`, which the verifier fails (case 11); the quotecheck self-test gains a positive case for the space and keeps its "shall" to "may" negative case.
- **Effect:** raw pages for DC are re-fetched under the fixed script; the first run's tallies (7 raw, 7 session) are kept in PILOT_REPORT.md.

## D-8. More audit false alarms, found on the LA pilot transcript; three fixes, both directions tested. Logged 3 Oct 2026, before any cross-check.

- **Found:** (a) a curl POST to the legislature's own law search form (`legis.la.gov/legis/LawSearch.aspx`) carries an ASP.NET `__VIEWSTATE=/wEPD...` base64 value, which the two-component path rule read as an absolute path (`=/wEPD.../`); (b) a grep pattern with escaped quotes, `"cbLaws_[0-9]*\">[^<]*"`, broke the quote stripper, so `>` read as a shell redirect; (c) the scratch-path mask replaced `/tmp/whr_...` inside `/private/tmp/whr_...` first and left a stray `/private`, so a (refused) `cd` into the session's own scratch dir read as a local path.
- **Fix:** (a) the generic two-component path rule no longer treats `=` as a path start (the explicit roots /etc, /Users, /private, /var, /tmp, /opt and the rest still do, after `=` too); (b) the quote stripper honours backslash escapes; (c) the longer scratch form is masked first.
- **Tested both ways:** good transcripts for the VIEWSTATE post, the escaped-quote grep and a refused cd into scratch; red ones for a refused `cd /Users/jas` (a local path survives refusal), a redirect hidden behind an escaped quote, and `--data "x=/etc/passwd"`.

## D-11. One more audit false alarm, found on the DC cross-check transcript. Logged 3 Oct 2026, before the pilot report.

## D-20 ADOPTED (JAS, 3 Oct 2026, "option 1"). The research transcript audit is replaced mid-run. Disclosed amendment.
